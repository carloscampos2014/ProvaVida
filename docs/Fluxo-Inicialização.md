## Floxo de Inicialização do App

1. Inicio
2. Banco de Dados Local Existe ?
    * Sim: Ir para o Passo 3
    * Não: Ir para o Passo 4
3. Banco de Dados Local está atualizado ?
    * Sim: Ir para o Passo 8
    * Não: Ir para o Passo 4
4. Criar/Atualizar Banco de Dados Local
5. Criação/Atualização do Banco de Dados Local foi bem sucedida ?
    * Sim: Ir para o Passo 8
    * Não: Ir para o Passo 6
6. Exibir mensagem de erro "Não foi possível criar/atualizar o banco de dados local."
7. Ir para o Passo 15
8. Existe Usuario Logado no App ?
    * Sim: Ir para o Passo 9
    * Não: Ir para o Passo 11
9. Abrir tela de Checkin
10. Ir para o Passo 16
11. O app tem acesso a Internet ?
    * Sim: Ir para o Passo 12
    * Não: Ir para o Passo 14
12. Abrir tela de Login
13. Ir para Passo 16
14. Exibir mensagem de erro "Não é possivel efetuar login/cadastro sem acesso a internet."
15. Encerrar App
16. Fim
